MacroTool 처음 사용 가이드

게임에서 반복하는 클릭·키 입력을 한 번 녹화해 두고, 단축키 하나로 다시 재생하는 프로그램입니다. 이 문서는 처음 써 보는 분이 첫 매크로를 만들고, 조금씩 고급 기능까지 익힐 수 있도록 순서대로 설명합니다.

무엇을 하는 프로그램인가

MacroTool은 싱글 플레이 게임에서 지루하게 반복하는 작업(같은 자리 클릭, 아이템 제작, 정해진 키 순서 등)을 대신 해 줍니다. 사용 흐름은 단 세 가지입니다.

① 녹화

평소처럼 직접 한 번 조작하면 마우스·키보드 입력과 그 사이 시간이 기록됩니다.

② 다듬기

필요 없는 입력을 지우고, 대기 시간을 고치고, 반복 횟수를 정합니다.

③ 재생

게임 안에서 지정한 단축키를 누르면 기록한 그대로 다시 실행됩니다.

익숙해지면 "화면에 이 버튼이 보일 때까지 기다렸다가 누르기", "보스가 보이는 동안 계속 공격하기" 같은 화면을 보고 판단하는 매크로도 만들 수 있습니다.

꼭 확인하세요 온라인 게임이나 안티치트가 있는 게임에서는 입력 자동화가 차단되거나 계정 제재를 받을 수 있습니다. 이 도구는 싱글 플레이 게임용입니다. 사용 전에 게임의 이용 약관을 확인하세요.

설치와 첫 실행

Windows 전용이며, 따로 Python 등을 설치할 필요가 없습니다.

  1. 압축 파일을 받아서 풉니다 MacroTool-windows.zip을 받아 쓰기 가능한 폴더(예: 문서\MacroTool\)에 풉니다. 바탕 화면이나 Program Files보다 문서 폴더를 권장합니다.
  2. 폴더째 둡니다 폴더 안에는 MacroTool.exe와 _internal 폴더가 있습니다. _internal은 실행에 꼭 필요하니 지우거나 옮기지 마세요. exe만 따로 꺼내면 실행되지 않습니다. 바탕 화면에서 실행하고 싶으면 exe의 바로 가기를 만드세요.
  3. MacroTool.exe를 실행합니다 처음 실행하면 Windows가 "PC 보호" 파란 경고창을 띄울 수 있습니다. 서명되지 않은 프로그램이라 생기는 것으로, 추가 정보 → 실행을 누르면 됩니다.
  4. 게임이 관리자 권한이면 이 프로그램도 관리자 권한으로 게임을 관리자 권한으로 실행하고 있다면 MacroTool도 exe를 우클릭 → 관리자 권한으로 실행해야 입력이 게임에 전달됩니다. 필요하면 시작할 때 경고가 표시됩니다.
백신이 막는다면 키 입력을 감지하고 입력을 대신 보내는 프로그램이라 Windows Defender 같은 백신이 의심 파일로 분류할 수 있습니다 (예: Trojan:Win32/Bearfoos.A!ml — 끝의 !ml은 "머신러닝 추정"이라는 뜻). 이 경우 MacroTool 폴더를 Defender의 제외 목록에 추가하세요.
게임은 창 모드로 게임 그래픽 설정에서 창 모드 또는 테두리 없는 창 모드를 고르면 가장 안정적으로 동작합니다. 독점 전체 화면에서는 상태 표시나 화면 판정이 안 될 수 있습니다.

매크로(macros 폴더)와 설정(settings.json)은 exe와 같은 폴더에 자동으로 만들어집니다. 다른 PC로 옮길 때는 폴더째 복사하면 됩니다. 프로그램이 오류로 꺼지면 같은 폴더에 crash.log가 남습니다.

첫 매크로 만들기

예시: 게임에서 "작업대를 클릭 → E 키로 제작"을 반복하는 매크로를 만들어 봅니다.

  1. 게임과 MacroTool을 함께 켭니다 게임은 창 모드로 두고, 녹화하려는 작업을 바로 시작할 수 있는 위치에 캐릭터를 세워 둡니다.
  2. 편집할 수 있게 "실행 불가"로 바꿉니다 메인 화면의 초록 버튼 ● 매크로 실행 가능을 눌러 회색 ○ 매크로 실행 불가로 만듭니다.
  3. + 추가를 누르고 이름과 시작 핫키를 정합니다 이름은 알아보기 쉽게(예: 제작 반복). 시작 핫키 칸 옆 키 입력으로 지정을 누른 뒤 원하는 키(예: F6)를 누르면 됩니다. Ctrl+F1처럼 두 키 조합도 됩니다. 게임에서 쓰지 않는 키를 고르세요.
  4. (권장) 대상 창 제목을 적습니다 오른쪽 매크로 설정의 대상 창 제목에 게임 창 제목 일부(예: Stardew)를 적습니다. 그러면 ① 그 게임 창이 앞에 있을 때만 입력을 보내고, ② 게임 창 위치가 바뀌어도 같은 자리를 클릭합니다.
  5. 녹화합니다 ● 녹화를 누르면 카운트다운(기본 3초)이 시작됩니다. 그 사이에 게임 창을 클릭해 앞으로 가져오고, 평소처럼 작업을 한 번 합니다. 끝나면 F8을 눌러 녹화를 멈춥니다.
    녹화 종료는 F8로 ● 녹화 버튼을 다시 눌러 끝내면 그 클릭까지 기록됩니다. 기록됐다면 목록 맨 끝 항목을 지우면 됩니다. F8은 녹화 화면이 열려 있으면 언제든 즉시 녹화를 시작·종료합니다.
  6. 테스트 재생으로 확인합니다 ▶ 테스트 재생을 누르고 카운트다운 동안 게임 창으로 전환하면, 녹화한 대로 움직이는지 볼 수 있습니다. 멈추려면 F9. 마음에 안 들면 다듬기를 하거나 목록을 지우고 다시 녹화합니다.
  7. 반복 횟수를 정하고 저장합니다 매크로 설정의 반복 횟수에 원하는 숫자(무한 반복은 0)를 적고 저장을 누릅니다. 저장하면 기록 화면이 닫힙니다.
  8. 다시 "실행 가능"으로 바꾸고 게임에서 사용합니다 메인 화면 버튼을 눌러 ● 매크로 실행 가능(초록)으로 돌립니다. 이제 게임 창에서 F6을 누르면 시작, 다시 누르면 멈춥니다.
녹화를 이어 붙일 수 있어요 녹화를 여러 번 하면 새 녹화 내용이 목록 끝에 추가됩니다. 앞부분을 다시 하고 싶으면 그 항목들을 지우고 녹화한 뒤 ▲ 위로로 옮기세요.

녹화한 내용 다듬기

기록 화면의 목록에서 한 줄이 입력 하나입니다. 앞 지연(ms)은 "바로 앞 입력이 끝나고 얼마나 기다렸다가 이 입력을 하는지"를 1/1000초 단위로 나타냅니다(1000 = 1초).

기본 편집

  • 수정: 줄을 더블클릭하거나 선택 후 수정. 지연 시간·좌표·키 등을 바꿀 수 있습니다.
  • 삭제: 여러 줄을 Ctrl/Shift+클릭으로 골라 삭제 또는 Delete.
  • 순서 바꾸기: ▲ 위로 / ▼ 아래로.
  • 되돌리기: ↶ 되돌리기(Ctrl+Z), ↷ 다시 실행(Ctrl+Y). 최대 100단계.
마우스 이동은 한 줄로 묶여 보입니다 마우스를 움직인 궤적은 수십 개의 점이지만 목록에는 마우스 이동 경로 한 줄(시작→끝 좌표, 이동 시간)로 표시됩니다. 수정 창에서 이동 시간이나 끝 위치를 바꾸면 경로 전체가 자연스럽게 맞춰집니다.

반복하기

반복 방법은 두 가지가 있고, 함께 쓸 수도 있습니다.

매크로 전체 반복

매크로 설정의 반복 횟수. 목록 전체를 처음부터 끝까지 N번(0 = 멈출 때까지 무한) 실행합니다. 반복 간 대기로 회차 사이 쉬는 시간을 둘 수 있습니다.

일부 구간만 반복

흐름: 줄의 🔁 while. 목록의 일부만 여러 번 돌립니다. 예: "준비 동작 1번 → 공격 10번 → 정리 1번".

구간 반복 만드는 법

  1. 반복할 줄들을 선택합니다 첫 줄을 클릭하고 Shift+마지막 줄 클릭.
  2. 🔁 while을 누릅니다 조건은 횟수(기본)를 그대로 두고 반복 횟수를 적은 뒤 확인.
  3. 목록이 이렇게 바뀝니다
    …🔁 반복 시작 ×10
    │ 마우스 클릭 왼쪽
    │ 키 입력 e
    🔁 반복 끝
    안쪽 줄은 │로 들여쓰기되어 보입니다. 반복 안에 또 반복을 넣을 수도 있습니다.

시작이나 끝 줄 하나를 지우면 짝도 함께 지워지고, 안의 입력들은 그대로 남습니다. 아무것도 선택하지 않고 추가하면 끝에 빈 반복 구간이 생기며, 그 사이에 입력을 넣으면 됩니다. 반복 시작 줄을 수정하면 같은 창이 열려 횟수를 바꾸거나, 조건으로 바꿔 동안 반복(아래 장)으로 만들 수 있습니다.

화면을 보고 반응하기

여기부터는 고급 기능입니다. 정해진 시간대로만 움직이는 매크로는 게임이 조금만 느려져도 어긋나는데, 화면을 보고 판단하게 하면 훨씬 튼튼해집니다. 기록 화면의 흐름: · 조건: · 변수: 줄 버튼들을 씁니다.

화면 판정의 두 종류

📷 이미지가 보일 때

버튼·아이콘 같은 그림을 잘라 두고, 화면에서 그 그림을 찾습니다. 일치도 기준(기본 85%) 이상 비슷하면 "보인다"로 판정.

🎨 범위의 색이 맞을 때

체력바 같은 영역을 드래그해 색을 정합니다. 그 범위에서 목표 색이 일정 비율(기본 50%) 이상이면 충족. 한 점만 보려면 너비·높이를 1로.

둘 다 반대로를 체크하면 "아닐 때"가 됩니다(예: 로딩 화면이 사라질 때). 설정 창의 🔍 지금 찾아보기를 누르면 지금 화면에서 바로 판정해 일치도를 보여 주니, 기준값을 정할 때 활용하세요.

🔍 await — "~가 보일 때까지 기다리기"

  1. 🔍 await를 누르고 📷 화면에서 잘라내기 카운트다운 동안 게임 화면을 띄워 둡니다.
  2. 캡처된 화면에서 찾을 부분을 드래그 잘라낸 그림과, 그 주변의 검색 영역이 자동으로 채워집니다.
  3. 최대 대기 시간을 정합니다 0은 무제한. 시간이 지나도 안 보이면 재생 중지(기본) 또는 계속 진행을 고릅니다.

기다린 만큼 뒤의 입력이 모두 함께 뒤로 밀리므로, 입력 사이 간격은 그대로 유지됩니다.

🖱 이미지 클릭 — "그 버튼이 보이면 눌러"

이미지가 화면에 나타날 때까지 기다렸다가, 찾은 위치의 가운데를 클릭합니다. 버튼 위치가 매번 조금씩 달라지는 게임에서 유용합니다. 보정 X, Y로 클릭 지점을 살짝 옮길 수 있습니다.

흐름 제어 — 만약 · 동안 반복 · 반복 탈출

"만약 ~라면", "~인 동안 반복", "~이면 반복 그만" 같은 흐름 제어는 흐름: 줄 버튼으로 넣습니다. 조건 창에서 이미지 / 범위 색 / 변수 / 여러 조건 중 하나를 바로 고르면 됩니다.

버튼하는 일
❓ if선택한 줄들을 ❓ if [조건] ~ ❓ if 끝으로 감쌉니다. 조건이 맞을 때만 실행. 'else' 구간도 만들기를 체크하면 맞지 않을 때 실행할 ↪ else 구간도 생깁니다.
🔁 while에서 조건 선택동안 반복(🔂 while ~ 🔂 while 끝): 한 바퀴 돌기 전마다 조건을 확인해, 맞는 동안 계속 반복합니다.
⏹ break조건이 맞으면 지금 돌고 있는 가장 안쪽 반복을 끝내고 다음으로 넘어갑니다. 반복 횟수 0(무한)과 함께 쓰면 "~가 보일 때까지 반복"이 됩니다.

여러 조건을 고르면 조건(이미지/범위 색/변수)을 2개 이상 넣고 모두 맞을 때(그리고) 또는 하나라도 맞을 때(또는)로 묶습니다.

📌 const — 판정에 이름 붙이기

같은 화면 판정을 여러 곳에서 쓸 때는 변수: 줄의 📌 const로 이름을 붙여 두면 편합니다.

  1. 📌 const로 이름을 붙입니다 예: 변수 이름 보스, 조건 = 이미지 "보스 체력바가 보일 때". 이 줄은 판정을 하지 않고 "보스라는 이름은 이 판정"이라고 정해만 둡니다. 그래서 변수를 쓰는 줄보다 앞쪽에 있어야 합니다.
  2. 조건에서 변수를 고릅니다 변수가 쓰일 때마다 그 순간의 화면으로 다시 판정합니다. 예를 들어 while의 조건에 쓰면 바퀴마다 화면을 다시 봅니다.

변수 지정은 재생 회차마다 비워지고, 지정되기 전에 쓰이면 "아니다(거짓)"로 봅니다.

🖼 이미지 변수 — 그림에 이름 붙이기

이미지 조건과 이미지 클릭에서 찾을 이미지: 이미지 변수로 골라 쓰는 그림입니다. 변수: 줄의 🖼 이미지 변수로 추가합니다.

잘라낸 이미지 (고정)

📷 화면에서 잘라내기로 자른 그림을 이름으로 담습니다. 같은 그림을 여러 곳에서 쓸 때, 그림을 바꾸려면 이 줄 하나만 고치면 됩니다.

재생 중 화면 캡처

재생 중 이 줄에 도달한 순간 지정한 영역을 캡처해 담습니다. 예: 시작할 때 화면 일부를 기억해 두고, 같은 영역에서 그 그림이 반대로(안 보이면) ⏹ break → "화면이 바뀔 때까지 반복".

재생 중 캡처는 편집 화면에서 내용을 알 수 없어 🔍 지금 찾아보기에서는 "아니다"로 봅니다. 한 가지 색으로만 된 그림은 찾을 수 없으니, 색만 볼 때는 범위 색 조건을 쓰세요.

알아 두면 좋은 점

  • 화면 판정은 주 모니터에서만 됩니다.
  • 게임 해상도·UI 크기를 바꾸면 이미지가 안 맞을 수 있으니 다시 잘라내세요.

문제 해결 · 자주 묻는 질문

+ 추가 / 편집 버튼이 눌리지 않아요

매크로 실행 가능(초록) 상태에서는 편집이 잠깁니다. Ctrl+F12 또는 버튼으로 실행 불가로 바꾸세요.

단축키를 눌러도 게임에서 매크로가 시작되지 않아요
  • 메인 화면이 ● 매크로 실행 가능(초록)인지 확인하세요.
  • 게임이 관리자 권한으로 실행 중이면 MacroTool도 관리자 권한으로 실행해야 합니다.
  • 매크로에 시작 핫키가 지정되어 있는지 목록의 "시작 핫키" 열을 확인하세요.
재생은 되는데 게임이 입력을 무시해요
  • 관리자 권한 문제가 가장 흔합니다(위 항목 참고).
  • 키를 너무 짧게 눌러서일 수 있습니다. 설정의 키 최소 유지를 0.08 정도로 늘려 보세요.
  • 독점 전체 화면 대신 창 모드/테두리 없는 창 모드를 써 보세요.
  • 안티치트가 있는 게임은 자동 입력을 막을 수 있습니다.
클릭 위치가 녹화할 때와 달라요
  • 대상 창 제목을 적어 좌표를 창 기준으로 녹화하면 게임 창을 옮겨도 맞습니다.
  • 게임 창 크기가 바뀌었다면 창 크기에 맞춰 좌표 조정을 켜세요.
  • 3D 게임의 시점 회전이라면 상대 이동으로 녹화를 체크하고 녹화하세요.
재생이 멈추지 않거나 키가 눌린 채로 남았어요

F9(중지)를 누르고, 그래도 안 되면 F10으로 프로그램을 종료하세요. 종료 전에 눌려 있던 키·버튼을 모두 놓습니다. 무한 반복 매크로에는 최대 실행 시간을 걸어 두면 안심입니다.

게임에서 채팅할 때 매크로 키가 눌려 버려요

채팅 전에 Ctrl+F12로 실행 불가로 바꾸세요. 그동안 매크로 키는 게임에 그대로 전달됩니다.

await가 항상 "시간 초과"로 끝나요
  • 조건 설정 창의 🔍 지금 찾아보기로 일치도를 확인하고, 일치도 기준을 조금 낮춰 보세요(예: 85 → 75).
  • 잘라낸 이미지에 배경이 많이 들어갔거나 애니메이션되는 부분이 있으면 판정이 흔들립니다. 바뀌지 않는 부분만 작게 잘라내세요.
  • 독점 전체 화면에서는 화면을 읽지 못할 수 있습니다.
저장하려는데 오류가 나요

이름이 다른 매크로와 겹치거나, 시작 핫키가 다른 매크로와 겹치거나, F8~F10을 사용했거나, 녹화 내용에 핫키·제어 키가 들어 있으면 저장되지 않습니다. 안내 문구를 보고 해당 부분을 고치세요. 변수·이미지 변수를 쓰는데 그것을 지정하는 📌 const · 🖼 이미지 변수 줄이 없어도 저장되지 않습니다.

설정을 처음 상태로 돌리고 싶어요

프로그램을 끄고 MacroTool 폴더의 settings.json을 지우면 됩니다. 매크로(macros 폴더)는 그대로 남습니다.

매크로를 다른 PC로 옮기거나 백업하려면?

MacroTool 폴더 안의 macros 폴더를 통째로 복사하세요. 매크로 파일(.json)과 같은 이름의 이미지 폴더가 함께 있어야 합니다.
